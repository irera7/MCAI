# راهنمای استفاده از Training Dashboard

## مشکل: هیچ داده‌ای در Dashboard نمایش داده نمی‌شود

### علت
صفحه Training Dashboard **فقط زمانی داده واقعی نمایش می‌دهد که یک آموزش در حال اجرا باشد**. اگر هیچ آموزشی شروع نکرده‌اید، صفحه خالی خواهد بود.

### راه حل: چگونه آموزش را شروع کنیم

#### مرحله 1️⃣: ایجاد یک پروژه جدید

1. **از صفحه Home، کلیک کنید روی "Create New Project"**
2. **اطلاعات پروژه را وارد کنید:**
   - نام پروژه (مثلاً: "My Cat Dog Classifier")
   - نوع داده (Modality): `Image` را انتخاب کنید
   - توضیحات (اختیاری)
3. **کلیک کنید روی "Create Project"**

#### مرحله 2️⃣: آپلود کردن داده‌ها

1. **پروژه را باز کنید** (از صفحه Home، کلیک کنید روی پروژه)
2. **کلیک کنید روی "Upload Data" یا "Import Data"**
3. **یکی از روش‌های زیر را انتخاب کنید:**

**روش A: آپلود فایل ZIP**
```
my_dataset.zip/
├── train/
│   ├── cat/
│   │   ├── image1.jpg
│   │   ├── image2.jpg
│   │   └── ...
│   └── dog/
│       ├── image1.jpg
│       ├── image2.jpg
│       └── ...
└── val/
    ├── cat/
    │   └── ...
    └── dog/
        └── ...
```

**روش B: انتخاب فولدر**
- فولدری را انتخاب کنید که ساختار بالا را دارد

4. **منتظر بمانید تا آپلود تکمیل شود**

#### مرحله 3️⃣: پیکربندی آموزش

1. **در صفحه پروژه، اطلاعات زیر را وارد کنید:**

   - **Model Architecture**: `ResNet18` یا `ResNet50` (برای شروع)
   - **Number of Epochs**: `10` (برای تست سریع) یا `50` (برای آموزش واقعی)
   - **Batch Size**: `32` (پیش‌فرض) یا `16` (اگر RAM کم دارید)
   - **Learning Rate**: `0.001` (پیش‌فرض)
   - **Optimizer**: `Adam` (توصیه می‌شود)
   
2. **تنظیمات اضافی (اختیاری):**
   - **Data Augmentation**: ✅ فعال کنید (بهبود دقت)
   - **Early Stopping**: ✅ فعال کنید (توقف خودکار)
   - **Mixed Precision**: ✅ فعال کنید (سرعت بیشتر)

#### مرحله 4️⃣: شروع آموزش

1. **کلیک کنید روی "Start Training"** یا **"Begin Training"**
2. **منتظر بمانید تا آموزش شروع شود** (ممکن است چند ثانیه طول بکشد)
3. **صفحه Training Dashboard به طور خودکار باز می‌شود**

## استفاده از Training Dashboard

### ✅ زمانی که آموزش در حال اجرا است، خواهید دید:

#### 1. **نوار پیشرفت (Progress Bar)**
- نشان می‌دهد چند Epoch از کل تکمیل شده است
- مثال: `3 / 50 (6%)`

#### 2. **متریک‌های آموزش (Training Metrics)**
- **Train Loss**: مقدار Loss روی داده‌های آموزش (باید کاهش یابد)
- **Train Accuracy**: دقت روی داده‌های آموزش (باید افزایش یابد)
- **Val Loss**: مقدار Loss روی داده‌های اعتبارسنجی
- **Val Accuracy**: دقت روی داده‌های اعتبارسنجی

#### 3. **نمودارهای زنده (Live Charts)**
- **نمودار Loss**: نشان می‌دهد Train Loss و Val Loss در طول زمان
- **نمودار Accuracy**: نشان می‌دهد Train Acc و Val Acc در طول زمان

#### 4. **اطلاعات اضافی**
- **Status**: وضعیت فعلی (🔥 در حال آموزش، ✅ تکمیل شد، ❌ خطا)
- **ETA (Estimated Time)**: زمان تقریبی باقیمانده
- **Elapsed Time**: زمان سپری شده
- **Batch Speed**: سرعت پردازش (samples/sec)
- **Learning Rate**: نرخ یادگیری فعلی

#### 5. **لاگ‌ها (Logs)**
- پیام‌های دقیق از هر Epoch
- مثال: `09:15:23 - Epoch 5: Loss: 0.2341, Acc: 0.9123 - 2.5s/epoch`

## مثال کامل (تست سریع با داده‌های نمونه)

### اگر داده ندارید، از داده‌های نمونه استفاده کنید:

```bash
# 1. دانلود داده‌های نمونه (مثلاً Cat vs Dog از Kaggle)
# https://www.kaggle.com/c/dogs-vs-cats/data

# 2. ساختار فولدر:
cats_vs_dogs/
├── train/
│   ├── cat/ (100 تصویر)
│   └── dog/ (100 تصویر)
└── val/
    ├── cat/ (20 تصویر)
    └── dog/ (20 تصویر)
```

### پیکربندی برای تست سریع:
- Model: `ResNet18`
- Epochs: `5`
- Batch Size: `16`
- Learning Rate: `0.001`

**زمان تقریبی**: 2-5 دقیقه (بسته به سخت‌افزار)

## عیب‌یابی (Troubleshooting)

### ❌ مشکل: "Backend در دسترس نیست"
**راه حل:**
1. باز کنید Terminal/CMD جدید
2. اجرا کنید:
   ```bash
   cd D:\Project\ModelCreator\backend
   python main.py
   ```
3. منتظر بمانید تا ببینید:
   ```
   INFO: Uvicorn running on http://127.0.0.1:8181
   ```
4. Frontend را Restart کنید

### ❌ مشکل: "هیچ داده‌ای نمایش داده نمی‌شود"
**علت‌های احتمالی:**
1. ✅ آموزش شروع نشده است → **پیگیری مراحل بالا**
2. ✅ Backend متصل نیست → **چک کنید Backend در حال اجرا است**
3. ✅ Project ID اشتباه است → **از صفحه Home، پروژه صحیح را باز کنید**

### ❌ مشکل: "داده‌ها به‌روز نمی‌شوند"
**راه حل:**
1. چک کنید که آموزش واقعاً در حال اجرا است (در Backend باید لاگ‌ها را ببینید)
2. Refresh کنید صفحه (F5)
3. یا از صفحه پروژه، دوباره کلیک کنید روی "View Training Dashboard"

### ❌ مشکل: "خطای Out of Memory (CUDA)"
**راه حل:**
1. کاهش دهید Batch Size: `32` → `16` → `8`
2. استفاده کنید از مدل کوچک‌تر: `ResNet50` → `ResNet18`
3. یا غیرفعال کنید Mixed Precision

## نکات مهم

### ✅ داده‌های واقعی vs Mock Data
- **Dashboard فقط داده‌های واقعی نشان می‌دهد** (از API backend)
- **هیچ داده Mock/Hardcoded در Dashboard نیست**
- اگر آموزش در حال اجرا نباشد، صفحه خالی است

### ✅ Polling Interval
- Frontend هر **2 ثانیه** یک بار از Backend درخواست status می‌کند
- این به این معنی است که نمودارها **تقریباً real-time** هستند (با تاخیر حداکثر 2 ثانیه)

### ✅ Epoch Detection
- Dashboard فقط **یک بار برای هر Epoch** داده را به نمودار اضافه می‌کند
- این از duplicate شدن داده‌ها جلوگیری می‌کند
