# 🔧 تغییرات و بهبودهای اعمال شده

## 📋 خلاصه

تمام مشکلات UI و UX برطرف شدند و پیام‌های راهنما به فارسی اضافه شدند.

## ✅ مشکلات برطرف شده

### 1. مشکل لیبل‌گذاری فایل‌ها
**مشکل:** کاربر نمی‌توانست به فایل‌ها لیبل اختصاص دهد
**راه‌حل:**
- `DataContext` به درستی تنظیم شد
- پیام راهنما در ابتدای صفحه اضافه شد
- راهنمای مرحله‌به‌مرحله با MessageBox
- متن‌های فارسی برای راهنمایی کاربر

### 2. کرش برنامه
**مشکل:** برنامه crash می‌کرد
**راه‌حل:**
- Converter های مفقوده اضافه شدند:
  - `BoolToVisibilityConverter`
  - `SelectionBackgroundConverter`
  - `SelectionBorderConverter`
- Exception Handler های global اضافه شدند
- پیام‌های خطای فارسی و واضح

### 3. UI نامفهوم
**مشکل:** کاربر نمی‌فهمید چه کاری باید انجام دهد
**راه‌حل:**
- تمام متن‌ها به فارسی ترجمه شدند
- راهنماهای inline اضافه شدند
- پیام‌های کمکی در هر مرحله
- نمادهای بصری (💡، 📌، ➕، etc.)

## 🎯 نحوه استفاده (برای کاربر)

### Import و لیبل‌گذاری داده‌ها:

1. **ایجاد لیبل‌ها (سمت راست)**
   - در کادر "افزودن لیبل جدید" نام لیبل را بنویسید
   - مثال: `گربه`, `سگ`, `پرنده`
   - دکمه "➕ افزودن" را بزنید
   - حداقل 2 لیبل نیاز است

2. **Import فایل‌ها**
   - دکمه "انتخاب فایل‌ها" یا "انتخاب فولدر" را بزنید
   - یا فایل‌ها را Drag & Drop کنید
   - فایل‌ها در لیست نمایش داده می‌شوند

3. **لیبل‌گذاری**
   - در لیست فایل‌ها، هر ردیف یک منوی کشویی دارد
   - منو را باز کنید و لیبل مناسب را انتخاب کنید
   - برای همه فایل‌ها تکرار کنید
   - حداقل 50% باید لیبل داشته باشند

4. **ادامه**
   - دکمه "Next: Select Model →" را بزنید
   - اگر مشکلی باشد، پیام راهنما نمایش داده می‌شود

## 📊 آمار داده‌ها

در پنل سمت راست، آمار زیر نمایش داده می‌شود:
- **Total Samples:** تعداد کل فایل‌ها
- **Labeled:** تعداد فایل‌های لیبل‌دار
- **Unlabeled:** تعداد فایل‌های بدون لیبل

## ⚠️ نکات مهم

1. **ترتیب کار:**
   - اول لیبل بسازید
   - بعد فایل import کنید
   - سپس لیبل‌گذاری کنید

2. **حداقل نیازمندی‌ها:**
   - حداقل 2 لیبل
   - حداقل 1 فایل
   - حداقل 50% لیبل‌گذاری شده (توصیه: 80%+)

3. **پیام‌های راهنما:**
   - هنگام باز شدن صفحه
   - هنگام اضافه کردن لیبل
   - هنگام import فایل
   - هنگام کلیک روی Next

## 🐛 رفع اشکال

اگر منوی کشویی لیبل‌ها خالی است:
1. مطمئن شوید حداقل یک لیبل اضافه کرده‌اید
2. صفحه را Refresh کنید (Back و Forward)
3. پروژه را ببندید و دوباره باز کنید

اگر برنامه crash کرد:
1. پیام خطا را بخوانید (به فارسی است)
2. Backend را چک کنید که روی port 8181 در حال اجرا باشد
3. Log های Console را بررسی کنید
